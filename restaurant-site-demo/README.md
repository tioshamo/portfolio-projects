# Restaurant Site Demo

飲食店サイトをテーマに、テイストの異なる複数のデザイン案を模擬制作したポートフォリオ用フォルダです。  

## ポートフォリオ要約

- カフェ、フレンチ、日本料理、居酒屋、バーなど業態ごとにUIの方向性を切り替え
- 静的なHTMLサイトとして、トップページ、メニュー、予約導線など店舗サイトの基本導線を構成
- ブランド設計を意識し、店舗ごとに異なる余白、色、書体、演出を設計

## 収録デモ

### 1. `coffee1/`

**ZENITH COFFEE LAB**  
都会的で洗練されたコーヒーショップを想定したデモです。

- ページ構成: `home/`, `about/`, `menu/`
- 特徴: モダンで上質なビジュアル、ヒーローセクション、商品訴求、複数ページ遷移

### 2. `coffee2/`

**KOMOREBI COFFEE**  
やわらかい色調とアプリ風UIを組み合わせたカフェサイトです。

- ページ構成: `home/` 内でビュー切り替え
- 特徴: ガラス調UI、カート風UI、プロフィール導線、メニュー閲覧の一体型レイアウト

### 3. `french/`

**L'AUBE**  
高級フレンチレストランを想定した、静けさと上品さを重視したデモです。

- ページ構成: `home/`, `menu/`, `reservation/`
- 特徴: エディトリアルな余白設計、タイポグラフィ重視、予約ページを含む複数ページ構成

### 4. `japanese/`

**白露 Hakuro**  
和の質感と現代的な見せ方を組み合わせた日本料理店サイトです。

- ページ構成: `home/`, `reservation/`
- 特徴: 縦書き表現、和紙調の演出、パララックス、スクロール連動アニメーション、予約フォームのモック挙動

### 5. `izakaya/`

**NEO SAKABA - SUICO -**  
ネオ居酒屋をテーマに、ポップで勢いのある世界観を前面に出したデモです。

- ページ構成: `home/`, `menu/`
- 特徴: ネオブルータリズム寄りの配色とレイアウト、強いタイポグラフィ、インパクト重視のUI

### 6. `bar/`

**NOCTURNAL**  
没入感のあるラグジュアリーバーをイメージしたデモです。

- ページ構成: `home/`
- 特徴: ダークトーン、グラスモーフィズム、カスタムカーソル、視覚演出を重視したランディングページ


## 閲覧方法

ビルドは不要です。各デモの `index.html` をブラウザで開くことで確認できます。

- `coffee1/home/index.html`
- `coffee2/home/index.html`
- `french/home/index.html`
- `japanese/home/index.html`
- `izakaya/home/index.html`
- `bar/home/index.html`

ローカル画像に加えて、Google Fonts や CDN を利用しているページがあるため、見た目を完全な状態で確認する場合はインターネット接続がある環境での閲覧を想定しています。
