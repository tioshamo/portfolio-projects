# Portfolio Kit

このファイルは、ポートフォリオサイトや GitHub README に載せる説明文と、スクリーンショットの撮り方をまとめたものです。

## 短い紹介文

日本語話者向けの AI 英単語学習アプリ。英単語や英文を解析し、単語帳保存と反復テストまで一貫して行えます。

## やや詳しい紹介文

日本語の発音説明、英単語、英文、日本文の 4 パターンを AI で解析し、意味、発音、品詞、例文を整理して返す英単語学習アプリです。調べた語句はそのまま単語帳に保存でき、SQLite に永続化したデータを使って反復テストまで行えます。Flask、SQLite、Vanilla JavaScript、Anthropic API を使って構築しました。

## アピールポイント

- AI の応答を JSON に固定して、バックエンドとフロントエンドの受け渡しを安定化
- 単語検索だけでなく、保存、非表示管理、テスト生成まで一続きの学習導線を実装
- `quiz_pool` により同じ単語ばかり出ないように制御
- 回答結果に応じて `difficulty` を更新し、苦手単語を可視化

## デモ動画の流れ

60 秒前後で十分です。次の順番で撮ると伝わりやすくなります。

1. AI チャットに入力して解析結果を表示
2. 単語帳に保存
3. 単語帳一覧を開く
4. テストを生成して 1 問回答
5. 結果画面を表示
